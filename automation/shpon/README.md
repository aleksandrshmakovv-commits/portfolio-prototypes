# ШПОН · публичный демо-чат

Откройте `demo.html`. Шесть шагов помогают составить мебельный бриф: изделие, размеры, материал, бюджет, срок и модельный пример. Данные можно проверить, изменить и подтвердить либо начать заново.

## Ограничения публичной версии

- Это сценарий JavaScript в браузере, не работающий Telegram-бот и не модель ИИ.
- Контакт, имя и адрес не запрашиваются. Используйте только модельные пожелания.
- Подтверждение завершает сценарий только в текущей вкладке.
- Нет отправки заявок, Telegram-сообщений, уведомлений и синхронизации с кабинетом.
- Нет серверного или браузерного сохранения. Обновление страницы очищает бриф.
- Кнопка примера добавляет готовую модельную схему, а не загружает пользовательские фотографии.

В исходном локальном прототипе разработан отдельный Python-обработчик и серверная интеграция с кабинетом. Публичная демонстрация не использует его и не подключается к рабочим данным мастерской.

Для клиентского запуска Telegram-транспорт, сервер, хранение, уведомления, доступы и обработка данных подключаются и проверяются отдельно. Секреты и исходная рабочая конфигурация в публикацию не входят.

Все материалы — модельные прототипы и заготовки для демонстрации типовых задач. Не финальный клиентский продукт; возможны доработка и замена функций и дизайна.
