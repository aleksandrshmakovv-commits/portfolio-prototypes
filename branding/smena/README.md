# СМЕНА — комплект айдентики

Модельный проект портфолио для вымышленной городской кофейни навынос.

## Состав

- `brand-guide.html` + `styles.css` — автономный короткий бренд-гайд. После распаковки откройте brand-guide.html в браузере. В общем портфолио кейс находится в index.html.
- `sources/logo-wine.svg` — основной логотип.
- `sources/logo-pink.svg` — обратная цветовая версия.
- `sources/logo-black.svg` — одноцветная версия.
- `sources/symbol.svg` — знак из двух смещённых полос.
- `sources/pattern.svg` — фирменный паттерн.
- `assets/packaging.png` — визуализация стаканов и пакета.
- `assets/storefront.png` — визуализация фасада.
- `assets/logo-reference.png` — растровое превью векторного оригинала.
- `prompts.md` — промпты генерации визуализаций.

В SVG нет встроенных шрифтов или растровых изображений. Буквы логотипа нарисованы контурами. Для наборного текста в кейсе используется Golos Text с Google Fonts; офлайн — Arial. Файлы шрифта не включены в комплект.

Основные цвета RGB: винный #68192F, розовый #F5B4C9. Дополнительные: эспрессо #231921, светлый #E6E6E2.

Свободное поле: не менее четверти высоты букв вокруг видимых контуров. Рекомендованный минимум концепции: слово 160 px, знак 32 px. Сохранять пропорции, не добавлять обводки, тени или эффекты.

Изображения упаковки и фасада созданы встроенным ImageGen с векторным логотипом в качестве референса. Это концептуальные визуализации, не фотографии изготовленных носителей. Эталон для воспроизведения логотипа — SVG, а не изображение мокапа.

Печать не выполнялась. Цветоделение CMYK/Pantone, развёртки упаковки, вылеты, материалы, пробные оттиски, конструкции вывески и проверка товарного знака не входят в модельный проект. Реальные клиенты и коммерческие результаты не заявляются.
