# Global — ядро прототипа поддержки

Это **детерминированный прототип**, не подключённая языковая модель и не автономный ИИ-агент. Все данные и правила школы модельные. Внешних запросов, денежных операций, изменений настоящих аккаунтов и отправки сообщений здесь нет. Модель и интеграции подключаются отдельно через API заказчика; API оплачивается заказчиком. Подключение потребует настройки и проверки, а не только вставки ключа.

## Файлы и контракт

Сначала загрузить `data.js`, затем `core.js`. Оба файла работают как классические скрипты и создают `window.GlobalData` / `window.GlobalCore` (в Node VM — свойства globalThis). Исходные данные глубоко заморожены.

`GlobalData`: `school`, массивы `tickets`, `students`, `courses`, `knowledge`.

`GlobalCore.analyze({ticketId, message?, studentId?, forceEscalate?})` возвращает замороженный объект:

```text
{id,ticketId,category,status,student,course,message,
 steps:[{tool,title,input,output}],
 sources:[{id,title,quote}],draft,
 action:{type,label,requiresApproval:true,localOnly:true,...},reason}
```

Категории: `access`, `homework`, `certificate`, `refund`, `identity`, `unknown`.
Статусы: `approval`, `draft`, `escalation`, `clarification`.
Действия: `restore_access`, `reply`, `escalate`. `forceEscalate:true` создаёт ручную передачу, финансовая очередь возврата сохраняется.

`searchKnowledge(query,category?)` выполняет реальный локальный поиск по ключевым основам русских слов, нормализует регистр и ё/е. Возвращает `{id,title,quote,category,score}`. Нет предметного совпадения → в trace пустой `matches`; отдельное правило маршрутизации явно отмечено `policyId`, а не выдаётся за найденный предметный ответ. Цитата всегда дословная.

`createState()` создаёт независимое замороженное состояние `{events:[],accessOverrides:{},escalations:[],replies:[]}`.

`commit(result,state,{draft?})` — вызывается **только после подтверждения оператором в интерфейсе**. Возвращает `{ok:true,duplicate,event,state}`. Сохранить возвращённое `state` для следующего действия. Прежнее состояние не меняется. Отредактированный текст сохраняется как `draft`; он не управляет инструментами. До 6000 символов, пустой текст отклоняется.

Состояние хранится только в памяти: обновление страницы начинает новую демо-сессию. JSON-копии состояния или результата не принимаются как доверенные объекты. Повтор подтверждения того же анализа или повторного анализа того же текста не создаёт второго события. Повтор восстановления той же модельной записи также не создаёт нового изменения. Базовый реестр учеников остаётся неизменным: локальное изменение отражено отдельно в `accessOverrides` и журнале.

## Демо-обращения

| ID | Ветка | Итог после подтверждения |
|---|---|---|
| GL-2401 | Оплаченный курс, доступ заблокирован | Локальный override доступа ST-101 |

| GL-2406 | Нет ответа в базе | Локальная очередь сотрудника |

## Ограничения и будущая интеграция

Trace — выполненные фиксированные функции и их фактические входы/выходы. Это не рассуждение и не выбор инструментов языковой моделью. Сообщения учеников трактуются как данные. Команды из текста не выполняются; результат должен быть выдан этим экземпляром ядра, произвольные или изменённые объекты отвергаются. У распознавания подозрительных инструкций нет претензии на полноту защиты будущей модели; перед реальной интеграцией понадобятся отдельные тесты границ доверия и доступа к данным. Caller сам организует диалог подтверждения: ядро не может проверить физический клик оператора.

Позже: серверный адаптер API модели, проверка личности ученика, разграничение ролей оператора, allowlist инструментов, подтверждения действий, журналы, оценочные тесты и подключение реальных систем школы. Ключ API никогда не хранить в публичном frontend.
