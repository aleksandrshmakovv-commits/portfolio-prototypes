# Global — прототип ИИ-агента поддержки онлайн-школы

Название — **Global**, интерфейс — русский. Портфолио-проект на модельном брифе, без реального клиента, учеников и измеренных бизнес-результатов.

## Что работает сейчас

- Шесть обращений: заблокированный оплаченный курс, домашняя работа, сертификат, возврат, неизвестный ученик и вопрос вне базы знаний.
- Локальные инструменты: классификация по фиксированным правилам, поиск ученика, поиск правила, проверка оплаты/доступа и завершения курса, подготовка черновика или передачи сотруднику.
- Трассировка с фактическими входами и результатами, точная цитата, ручное редактирование ответа.
- Предпросмотр и подтверждение только локального действия. Отмена ничего не меняет; повторное выполнение заблокировано.
- Поиск, фильтры, база знаний, адаптивный интерфейс, копирование и JSON-экспорт.
- Состояние только в памяти вкладки. Перезагрузка или сброс возвращают исходные данные; никаких секретов и сохранённых ученических данных.

## Честное ограничение

Это **прототип будущего агента**, не действующий автономный ИИ. Модель не подключена и не выбирает инструменты: текущий порядок задаёт код. Настоящая школа, LMS, каналы отправки, платежи и изменение аккаунтов не подключены. Возврат — лишь локальный маршрут сотруднику, не денежная операция. Правила школы вымышлены, это не правила настоящего поставщика услуг.

## Будущая интеграция

Отдельный этап: серверный адаптер к API модели, доступ к согласованным данным школы, подключение канала поддержки и тестирование. Подключение API само по себе не делает все интеграции рабочими. Расходы на модель/API оплачивает заказчик. Ключ хранится на сервере, не в браузере. Подписка на чат не используется для доступа к API. Локальная модель для этого прототипа не требуется.

Предлагаемый контур: сообщение → модель на сервере → выбор только разрешённых инструментов → проверенные результаты и источники → черновик → подтверждение оператора → серверное действие с журналом и идемпотентным ключом. Для реальной школы потребуются аутентификация, разграничение доступа, минимизация персональных данных, защита от инструкций в сообщениях, лимиты и обработка ошибок. Они не заявляются реализованными в статическом демо.

## Посмотреть прототип

[Открыть Global](index.html) · [Кейс](case.html) · [Логика сценариев](README-core.md) · [Все работы](../../index.html).

Выберите обращение, запустите разбор, изучите выполненные шаги и источники. Отредактируйте черновик при необходимости. Предпросмотр и подтверждение выполняют только модельное действие в текущей вкладке; отмена ничего не меняет. Сброс возвращает исходный набор, не затрагивая другие проекты портфолио.

Если браузер ограничивает копирование, выделите ответ и скопируйте его вручную. JSON-экспорт скачивает результат на ваше устройство, не отправляя его на сервер.

Все материалы — прототипы и заготовки, а не финальная клиентская система. Дизайн, правила и функции могут дорабатываться и заменяться.
