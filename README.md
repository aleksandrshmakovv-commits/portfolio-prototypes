# Портфолио демонстрационных прототипов

14 модельных работ в 11 направлениях. Все версии демонстрационные и могут дорабатываться. Никаких реальных клиентских данных, оплаты, отправок ученикам или Telegram-токенов. HTML/CSS/JS опубликованы как автономная статическая витрина. Данные заказов сохраняются только в браузере посетителя; ИСТОК и чат бота используют отдельные локальные демо-адаптеры. API модели не подключён.
