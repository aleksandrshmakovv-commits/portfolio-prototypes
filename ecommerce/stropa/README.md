# СТРОПА — демонстрационный интернет-магазин

Откройте index.html в браузере. Сборка и сервер не требуются. case.html — оформленный кейс для портфолио.

## Рабочие сценарии

Каталог из трёх моделей в двух цветах (шесть вариантов товара), фильтры категорий, поиск по модели/цвету, сортировка цены, карточка товара, выбор цвета с заменой изображения, количество 1–8, быстрое добавление, корзина, изменение количества и удаление, два способа доставки, проверка полей формы, локальное подтверждение демо-заказа.

Демо-цены: Маршрут 22 — 8900 ₽; Петля 04 — 3900 ₽; Линия 16 — 4900 ₽. Доставка: пункт выдачи 300 ₽, курьер 500 ₽, бесплатно от 10000 ₽.

Корзина сохраняется в localStorage под ключом stropa-cart-v1. Форма не отправляется в сеть; контактные поля не сохраняются в localStorage. После демо-оформления корзина очищается. При блокировке localStorage корзина работает в пределах открытой вкладки.

## Границы демонстрации

Бренд, ассортимент, характеристики, остатки, цены и доставка смоделированы. Изображения созданы генеративно. Сервер, платёжная система, реальные заказы, склад и отправка уведомлений не подключены. Результаты продаж и реальные клиенты не заявляются. При отсутствии интернета Google Fonts заменяется системным шрифтом.

Это прототип, не финальный клиентский магазин. Дизайн, ассортимент и функции могут дорабатываться и заменяться.
