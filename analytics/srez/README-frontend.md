# СРЕЗ — интерфейс аналитики продаж

Прототип: [index.html](index.html). Это работающий статический интерфейс на HTML/CSS/JavaScript без внешнего API и без пользовательских заказов из других проектов.

## Реализовано

- Выбор дат, канала и категории с применением фильтров. Ошибка периода не заменяет уже применённый набор.
- Четыре KPI и сравнение с предыдущим периодом равной длины; кнопки `?` раскрывают формулы и ограничения.
- Нативный SVG-график фактической чистой выручки по дням или семидневным интервалам. Пустые дни, отрицательные столбцы и нулевая линия обработаны.
- Каналы продаж с фактическими, в том числе отрицательными, значениями.
- Таблица по шесть строк, переключение страниц и сортировка даты / номера / выручки. Поиск номера и товара меняет только таблицу; KPI и графики сохраняют выбранные фильтры.
- Локальный импорт CSV: выбор → проверка всего файла → предпросмотр первых пяти строк → явное применение. Любая ошибка сохраняет прежний набор. После применения период соответствует датам файла, канал и категория сбрасываются на «Все».
- Экспорт всех строк по периоду, каналу и категории в UTF-8 CSV с BOM и нейтрализацией строковых формул. Поиск таблицы в экспорт не входит. Пустой набор не создаёт бессмысленный файл.
- Возврат к демо требует подтверждения при наличии импортированного набора.
- «Обзор», «Заказы», «Данные» — ссылки на реальные разделы этой страницы, а не фиктивные экраны.

Файл остаётся в памяти текущей вкладки. Сетевые запросы с CSV или продажами не выполняются; localStorage не используется. Перезагрузка возвращает 90 демо-строк. Внешний запрос используется только для необязательного шрифта Manrope; без него применяется Arial.

## Работа с демо

1. Выберите даты, канал и категорию; нажмите применение фильтров.
2. Кнопки «?» рядом с KPI открывают методику. График можно переключить с дней на недельные интервалы.
3. Поиск номера или товара меняет только таблицу. Заголовки таблицы переключают сортировку, кнопки страниц — видимые строки.
4. Импортируйте [модельный CSV](sample-sales.csv), проверьте предпросмотр и явно примените новый набор. Не загружайте конфиденциальные клиентские данные в публичное демо.
5. Для возврата к исходным данным используйте сброс демо.

Для диапазона CSV более десяти лет приложение после импорта выбирает последние 30 дней; остальные строки остаются в памяти. Суммы в экспортируемом файле не округляются до целых рублей.

## Ограничения интерфейса

На небольшом экране блоки располагаются последовательно; таблицы допускают горизонтальную прокрутку. Реальные системы продаж и совместная работа не подключены. Показатели служат иллюстрацией модели расчёта, не бухгалтерской отчётностью.
