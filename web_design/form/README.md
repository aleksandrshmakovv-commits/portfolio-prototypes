# FORM: фитнес-клуб

Демонстрационный лендинг для портфолио. Бренд и данные смоделированы, это не заявленная работа для реального клуба.

## Что реализовано
- Адаптивный спортивный арт-дирекшн: большая типографика, графит/кислотный жёлтый, пять настоящих стоковых фотографий с Pexels, сохранённых локально.
- Направления тренировок и атмосфера клуба.
- Демо-расписание по семи дням недели, выбор занятия.
- Два абонемента и три длительности, месячная цена и стоимость всего периода.
- Нативный диалог записи: контекст, валидация, локальное подтверждение, клавиатура/ESC.
- FAQ, мобильное меню, reduced-motion, локальные шрифты с кириллицей.

## До рабочего запуска
Заменить название, фотографии, тексты, условия клуба и цены. Подключить реальные занятия, CRM/уведомления и серверную обработку заявок. Согласовать обработку персональных данных. Формы этого прототипа не делают запросов, не сохраняют данные в браузерное хранилище и не создают реальные записи.
