# LINO / товарная графика

Самостоятельный модельный дизайн-кейс. Вымышленный бренд косметики для волос; не коммерческий клиентский заказ. Упаковка, два объёма по 250 мл, компоненты и инструкции — проектная информация. Лечебных обещаний, сертификатов и утверждений о реальной эффективности нет.

## Комплект
- `svg/01-cover.svg` — обложка дуэта.
- `svg/02-choose.svg` — выбор шампуня и кондиционера.
- `svg/03-ingredients.svg` — иллюстративная концепция состава, не полный INCI.
- `svg/04-routine.svg` — модельный сценарий применения.
- `svg/05-set.svg` — комплектация и объёмы.
- `assets/01…05-*.png` — пять соответствующих экспортов 1080 × 1350 px.
- `assets/overview.png` — контактный лист 1892 × 586 px.

SVG автономны: фотография встроена как data:image/jpeg; основной текст остаётся редактируемыми элементами text. Векторные элементы — плашки, линии, подписи. Изображение упаковки и текст на самих флаконах растровые. Фотоассет создан встроенным imagegen; детерминированная верстка и PNG-экспорт выполнены отдельно.

Georgia + Arial; шрифты не встроены. При открытии в другой среде возможна замена шрифтов: PNG сохраняет проверенный внешний вид. Палитра: #F5F3EB / #24251F / #D4E58C. Формат карточек общий, композиции различаются.

## QA / 8 октября 2026
- Все 5 SVG открыты локальным Chrome headless; XML корректен, в каждом есть редактируемые text и встроенный data:image. Количество text: 9, 14, 22, 21, 11.
- Все 5 PNG повторно декодированы Pillow; каждый имеет 1080 × 1350 px.
- Контактный лист открыт для визуальной проверки; после неё обложка уточнена, чтобы сохранить нижнюю часть флаконов.
- HTML проверен в 1440 × 1000 и 390 × 844: горизонтального переполнения нет, локальные ссылки и изображения доступны, модальное увеличение и закрытие кнопкой/Escape работают, ошибок JavaScript нет.
- ZIP содержит ровно 12 файлов: 5 SVG, 5 PNG, контактный лист и этот README. CRC, SVG XML и PNG decoding проверены после упаковки. В архиве нет скриптов, временных файлов и QA-снимков.

Реальные продажи, доступность физического товара, свойства косметики и требования отдельных маркетплейсов не проверялись. Глицерин, пантенол и масло семян льна показаны только как иллюстрация концепции формулы. Для реального товара нужны утверждённые производителем этикетка, INCI, объёмы и инструкция.
